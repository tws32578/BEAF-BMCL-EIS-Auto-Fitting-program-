1. 설치와 실행

처음 한 번

  1. Windows PC에 Anaconda를 설치합니다. 설치할 때 Just Me를 고르고, 위치는 기본값(C:\Users\사용자이름\anaconda3) 그대로 둡니다.
  2. BEAF 폴더(zip)를 원하는 곳에 풉니다. 너무 깊은 경로는 피하세요 (예: 바탕 화면\BEAF).
  3. 설치.bat을 더블클릭합니다. 인터넷이 필요하고 처음에는 5~10분쯤 걸립니다. "설치 완료"가 나오면 창을 닫습니다.

매번

  1. 실행.bat을 더블클릭합니다. 검은 창이 뜨고 잠시 후 브라우저에 BEAF가 열립니다. 안 열리면 주소창에 http://127.0.0.1:8765를 입력하세요.
  2. 끝낼 때는 검은 창을 닫습니다.
설치 후에는 인터넷 없이 동작합니다. 모든 계산은 내 컴퓨터에서 하고, 데이터는 밖으로 나가지 않습니다. Claude 같은 AI도 쓰지 않습니다 — 결과와 설명 문장은 미리 정해 둔 계산·규칙으로 만들어집니다.

2. 사용 순서

화면은 위에서 아래로 한 흐름입니다.

  1. 데이터 — 파일을 끌어다 놓거나 폴더 경로를 붙여넣습니다.
    • 지원 형식: .mpt .mpr (EC-Lab), .xlsx .csv .txt (표)
    • 표 파일은 열 이름으로 주파수·임피던스를 찾습니다 (Re/Im 또는 |Z|/위상, Im 부호 자동 판단). 한 파일에 측정이 여러 개면 자동으로 나눕니다 (사이클·SOC·온도 열이 바뀌는 곳, 주파수가 다시 시작하는 곳).
    • 파일명·엑셀 열에서 읽은 온도·SOC·사이클 값은 표에서 고칠 수 있습니다. 체크를 끈 측정은 분석하지 않습니다.
    • "데이터 점"은 그 측정의 주파수 점 개수입니다.
  2. 셀 정보 (선택) — 셀 구성·전해질. 몰라도 분석됩니다. 반원 개수는 데이터로 정하고, 셀 정보는 성분 이름(R_SEI, R_ct …)을 붙이고 예상 반원 수를 후보에 더하는 데만 씁니다. '모름'이면 R1, R2 … (고주파 → 저주파). '더 알려주기'에서 전극 면적을 넣으면 Ω·cm²로도 보여 줍니다.
  3. 분석 버튼 — 진행도와 남은 시간이 표시됩니다. 측정 하나에 보통 1~2초.
  4. 결과 — 요약 표, 여러 측정 비교, 측정 하나 자세히, 엑셀로 내보내기.

3. 결과 읽는 법

상태

통과회로가 데이터를 잘 설명하고, 성분 값이 물리적으로 말이 됨
검토확인이 필요함 — 이유는 자세한 결과 위쪽에 표시 (예: 두 반원이 겹쳐 합만 믿을 수 있음, 잔차가 큼)
데이터 이상KK 검증 실패 — 측정 중 셀이 변했거나 잡음이 큼. 피팅 결과보다 측정을 먼저 확인

측정 하나 자세히

  • 설명 카드 — 저항 구성 막대, 성분별 의미(주파수·용량으로 짐작한 물리 과정), 확인할 점, 신뢰도. "보통 ~"이라는 해석은 흔한 경우일 뿐이니 최종 판단은 직접 하세요.
  • 그래프 탭 — Nyquist(성분별 반원), Bode, DRT, 원자료(모든 cycle, 측정값 그대로).
  • 파라미터 표 — 값 ± 표준오차. 겹친 반원은 '합만 신뢰' 경고와 합의 오차.
  • 후보 비교 — 다른 회로의 잔차·BIC·탈락 이유. 다른 회로를 골라 바꿀 수 있습니다.

직렬 저항: R0 · R_HF · L 보정 R0

고주파에 −Z″<0 구간(인덕턴스)이 있으면 직렬 저항이 정의에 따라 달라서 세 값을 함께 보여 줍니다 (요약 표, 상세 설명, 엑셀, 추세).

값뜻성질
R0 (추천 회로)추천 회로의 직렬 저항회로에 L 이 없으면 크게 나오는 쪽
R_HF−Z″ = 0 교차점의 실수부. 모델 없이 그래프에서 읽은 값 (수동 피팅 시작점, 많은 논문의 R_s) 측정끼리 비교·온도 경향에 가장 안정적. 다만 L 때문에 교차점이 반원 쪽으로 밀려 실제 옴 저항보다 큼
R0 (L 보정)같은 회로에 L 을 넣었을 때의 R0 물리적으로 더 정확한 쪽. 고주파가 45° 모양(다공성 전극)이면 R0 와 첫 반원이 구분되지 않아 '결정 안 됨'

실측 Gr‖Gr 에서 R_HF 는 L 보정 R0 보다 20~50 % 컸고, 온도 경향(Arrhenius R²)은 R_HF 가 0.96~1.00 으로 가장 매끄러웠습니다. 보고할 때는 어느 정의인지 밝히세요. 실제 옴 저항을 정확히 얻으려면 측정 단계에서 L 을 줄이는 것(짧고 꼬은 케이블, 4단자 연결, 단락 보정)이 가장 확실합니다.

그래프 조작

휠 = 확대/축소 · 드래그 = 영역 확대 · 더블클릭 = 원래대로 · 그래프 밖에서 휠 = 페이지 이동

4. 여러 측정 비교

측정은 각각 독립적으로 피팅합니다. 같이 넣은 측정은 비교와 회로 우선순위에만 씁니다.

  • 가로축·묶음 — 측정 사이에서 바뀌는 변수(온도·사이클·SOC …)를 가로축으로 자동 선택하고, 나머지로 묶습니다. 바꿀 수 있습니다.
  • 공통 회로 — 묶음 안에서 가장 많은 측정이 지지하는 회로. 어떤 측정에서 공통 회로가 그 측정의 1등과 거의 차이가 없으면(ΔBIC 10 이내) 공통 회로를 우선합니다.
  • 추세 — 각 측정에서 공통 회로로 피팅한 값을 모아 그립니다. 빈 원 = 그 측정에서 공통 회로가 탈락한 점, 빨간 테두리 = 추세에서 크게 벗어난 점.
  • Arrhenius — 가로축이 온도면 활성화에너지 Ea와 R²를 계산합니다.
  • Nyquist 겹쳐 보기 — 점 = 원자료(피팅 구간), 실선 = 그 측정을 공통 회로로 피팅한 곡선. 실선이 점을 잘 못 따라가는 측정은 공통 회로로 비교하기 어렵다는 뜻입니다.
  • 추세에 넣을 측정 고르기 — 행을 눌러 포함/제외. 묶음마다 '모두', '모두 빼기', '단독 추천도 같은 회로인 것만', '벗어난 점 빼기' 버튼.

5. 회로를 고르는 원리

BEAF는 데이터를 먼저 분석해 회로 모양을 짐작한 뒤, 블록으로 조립한 수십 개 후보만 시험합니다. 그래서 측정 하나에 1~2초면 끝납니다.

  1. KK 검증 — 측정이 정상인지 확인. 잔차 = 그 데이터의 잡음 수준.
  2. DRT — 스펙트럼을 시정수 분포로 바꿔 "과정이 몇 개, 어느 주파수에" 있는지 셉니다. 겹친 반원도 피크로 나뉩니다. λ 세 가지로 계산해 모두에서 나온 피크만 인정합니다.
  3. 후보 조립 — 블록을 붙여 만듭니다. 
    [L] ─ R0 ─ (R‖Q) × n ─ [꼬리: Q / Wo / W]
    n = DRT 피크 수 ± 1 (최대 6, 필요하면 늘려 봄). L 있음/없음, 꼬리 종류, Gerischer·다공성 전극(TLM) 같은 모양 회로도 함께.
  4. 피팅 — DRT 피크 위치·크기를 시작값으로, 시작점을 바꿔 여러 번 (병렬 계산).
  5. 탈락 — 잘 맞아도 물리적으로 말이 안 되면 뺍니다 (아래 판정 기준).
  6. 순위 — 유효 → DRT 피크와 일치 → BIC 최소. BIC는 파라미터가 많으면 벌점을 주므로 반원을 하나 더 넣어 조금만 더 잘 맞는 회로는 이기지 못합니다.
Gerischer · TLM이 일반 회로와 다른 점

일반 R‖Q는 한 곳에서 일어나는 과정 하나(반원 하나)입니다. TLM(전송선 모델)은 두께가 있는 다공성 전극에서 기공 속 이온 저항이 깊이 방향으로 퍼져 있는 구조로, 고주파의 약 45° 직선 + 반원이 특징입니다. Gerischer는 확산하면서 반응이 함께 일어나는 과정으로, 45°로 시작하는 비대칭 반원입니다. 둘 다 무한히 많은 작은 소자가 연속으로 퍼진 구조라 R‖Q 몇 개로는 정확히 표현되지 않습니다. 다만 데이터만으로 파라미터(R_ion, R_ct)가 잘 갈리지 않을 수 있으니 값은 신중히 보세요.

한계: 블록 조합으로 만들 수 없는 회로(반원 안에 반원이 들어간 중첩 구조 등)는 찾지 못합니다. 그럴 때는 분석 설정 창의 '등가회로 → 직접 고르기'에서 목록이나 직접 입력으로 회로를 지정하세요.

6. 판정 기준

상황BEAF의 처리
R의 오차가 값보다 큼데이터가 그 성분을 결정하지 못함 → 탈락
반원이 전체 저항의 1 % 미만사실상 없는 반원 → 탈락
반원이 측정 주파수 범위 밖근거 없음 → 탈락
반원 위치가 DRT 피크와 0.5 decade 이상 어긋남겹친 반원을 CPE로 뭉갠 해일 가능성 → 탈락
저항이 탐색 경계에 붙음탈락 (α 등은 '상한 도달' 표시)
두 R의 상관 < −0.9'합만 신뢰' 경고 + 합과 합의 오차 표시
잔차 > max(3 × KK 잡음, 2 %)검토
KK 잔차 > 2 %데이터 이상
고주파 인덕턴스 영역 (−Z″ < 0)기본은 피팅에서 제외. L 후보는 교차점 근처 점으로 L 값을 정함. 이 영역은 케이블·장비 효과가 섞여 단순 L 로 잘 맞지 않아, 넣으면 반원 쪽과 R0 가 흔들림
성분 순서시정수(τ) 크기로 자동 정렬 — 작은 τ = 고주파 쪽
